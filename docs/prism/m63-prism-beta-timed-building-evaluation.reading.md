# Prism Alpha v0.1.5：固定的大牌冲分检查点

已发布Prism Alpha v0.1.5：greedy对Balance父代53.91%、对Prism Alpha v0.1.4为51.95%，相对父代略偏大牌冲分。

**产物：Prism Alpha v0.1.5已发布。** 沿用已验核的M63最终c4；版本、权重与Balance血缘已绑定。

**实战：对父53.91%，对Alpha51.95%。** 相对父代，对Heuristic和初代提高；对Alpha和上一Beta略低，通用版接近。

**画像：Alpha路线：大牌冲分略增强。** 小牌略少、得分效率与冲分时点略升；未证明全面超过现任Alpha。


Prism Alpha v0.1.5 就是 M63 原Beta目标分支最终 c4，固定权重未变；由 Prism Balance v0.1.0 继续 PPO 训练得到，不是 Prism Alpha v0.1.4 续训的后代。此次发布没有再次训练。

模式：双方greedy。
