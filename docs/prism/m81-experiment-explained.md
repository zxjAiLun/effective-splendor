这轮是棋力效果的 A/B 对照实验。A、B 都从 M75 c20 出发，各训练 5,120 局；B 只改变训练对手配比。它要回答：补上启发式和旧 Balance，能否改善这两个对手的成绩，同时守住整体棋力？

## A 先说清楚：从哪个模型开始？
**共同父模型是 M75 c20。c20 表示第 20 个训练周期结束后的权重。**

```flow LR
[M75 c20] -> [M79 c20]: 历史原配比追加训练
[M75 c20] -> [M81 A c20]: 新种子，原配比对照
[M75 c20] -> [M81 B c20]: 同组新种子，补入两个对手
```

M79 的退步促成这轮实验，但 M79 不是这轮的初始化权重。M81 沿用它的训练参数，两臂都重新初始化优化器和随机状态。

| 名称 | 在本轮中的身份 |
|---|---|
| M75 c20 | 两臂共同起点，也是评测基线 |
| M79 c20 | 提出问题的历史实验；不是本轮父模型 |
| M80 | 本地历史清理与 Studio 退役工程；不是训练模型 |
| c15 | 第15周期检查点；本轮不拿它作为起点或最终候选 |

你提到的“MC15”没有对应到当前合同的精确型号；实际输入已经锁定为 M75 c20。

## B 为什么值得花时间做这一轮？
M79 对父代直接交手占优，但对部分旧对手的成绩下降。只继续加训，无法分清是训练收益还是覆盖代价。

| 旧评测对手 | M75 得分 | M79 得分 | 变化 |
|---|---:|---:|---:|
| 启发式 v0.3.1 | 91.50% | 86.33% | −5.18 个百分点 |
| Balance v0.1.0 | 73.24% | 71.00% | −2.25 个百分点 |

2,048 局旧回放显示，得分下降配对的决策分歧多发生在前12步。拿宝石颜色与组合的改变很常见。M79 虽然预留更多，却更快买回预留牌，也更少漏掉能直达15分的购牌机会。因此直接惩罚预留，依据不足。

启发式下降的事后95%区间为 −8.79 至 −1.56 个百分点。旧 Balance 区间为 −7.32 至 +2.73，尚不能确认真实退化。

**要检验的解释：原训练池没有这两个对手，追加训练可能偏向其他对手的打法。** 回放提出假设；这轮新训练才检验干预是否有效。

## C A、B 到底哪里不同？
每组都是20周期，每周期256局。总训练量、起点、网络、奖励、参数和训练种子全部匹配。

| 训练对手 | A：原配比，5,120局 | B：补覆盖，5,120局 |
|---|---:|---:|
| Prism v0.1.1 | 25% · 1,280局 | 18.75% · 960局 |
| M75 c20 | 25% · 1,280局 | 18.75% · 960局 |
| Alpha v0.2.0 | 25% · 1,280局 | 18.75% · 960局 |
| Balance v0.2.1 | 25% · 1,280局 | 18.75% · 960局 |
| 启发式 v0.3.1 | 0局 | 12.5% · 640局 |
| Balance v0.1.0 | 0局 | 12.5% · 640局 |

**唯一干预：把四个原对手各让出6.25%的份额，分给两个新增对手。** 75%的任务连对手、环境种子和座位都相同。其余25%保留环境种子和座位，只换对手。

A 是必要对照：若只将 B 与旧 M79 比，训练随机性和新对手配比会混在一起。两组都从同一父代开始，才有较清楚的配比比较。

这检验的是“从 M75 重新追加训练时，改配比是否更好”。它不直接回答“已经训练好的 M79 能否被修复”。

## D 怎么训练，最终拿哪个模型比较？
两臂分别从同一 M75 权重开始，使用新的 AdamW 优化器。采用相同随机初始化状态；训练环境种子为81001000至81003559，每个种子双座位。

| 固定项目 | 设置 |
|---|---|
| 算法与架构 | 沿用 M79 的 PPO 和网络 |
| 学习率 | 0.00003 |
| 每批训练轮数 / 小批大小 | 2 / 256 |
| PPO 裁剪 / 熵系数 | 0.2 / 0.01 |
| GAE / 梯度范数上限 | 0.95 / 1.0 |
| 目标 KL / value 权重 | 0.02 / 0.5 |
| 奖励 | 沿用胜负目标；风格奖励系数为0 |
| 训练出招 | 候选按概率采样，对手 greedy |
| 最终产物 | A c20 对照；B c20 固定候选 |

c5、c10、c15 留档，不做中途选优。独立评测开始后，不能看成绩换成 A 或某个较好的中间检查点。

这轮只有一组配对训练种子。它是方法筛选小试，不能证明这个配比换一个训练种子仍然有效。

## E 怎么评测，为什么不能看训练胜率就下结论？
训练胜率受采样方式和对手配比影响。最终使用新的独立种子，双方都用 greedy，所有模型面对相同局面与座位安排。

| 评测部分 | 计算 | 计划局数 |
|---|---|---:|
| M75、A、B 对八个对手 | 3模型 × 8对手 × 512局 | 12,288 |
| A、B 直接对父代 M75 | 2模型 × 1,024局 | 2,048 |
| 全部独立评测 | 上述两部分之和 | 14,336 |

八个对手是启发式、Prism v0.1.1、Balance v0.1.0、Alpha v0.1.4、Beta v0.1.0、Alpha v0.1.5、Alpha v0.2.0、Balance v0.2.1。

每个512局单元含256个环境种子，双方交换座位。M75 基线只评一次，A/B 共用该基线。

主指标为 **半平得分＝（胜局＋0.5×平局）÷全部有效终局**。差值用相同种子的双座位配对计算区间，不把先后手当成完全独立样本。重采样20,000次。

新增的两个对手在 B 的训练里已经出现。对它们的新种子成绩属于已见对手的保持能力。三个旧 Alpha/Beta 版本提供训练外对手覆盖。

## F 什么结果算有效？两个问题分开回答
**问题一：补覆盖是否优于原配比？比较 B 与 A。**

| 指标 | 通过要求 |
|---|---|
| 启发式与旧 Balance 等权平均 | 至少提高2个百分点，单侧95%下界大于0 |
| 八对手平均 | 差值下界不低于−2个百分点 |
| Alpha v0.2.0、Balance v0.2.1 | 各自差值下界不低于−3个百分点 |

后三项按同一组多重比较校正。必须全部通过；仍逐项展示两个目标对手，防止平均值遮住其中一个下降。

**问题二：B 是否值得接替 M75 作为主线父候选？比较 B 与 M75。**

| 指标 | 通过要求 |
|---|---|
| 原六对手共同池 | 至少提高2个百分点，差值下界大于0 |
| 直接对 M75 | 得分至少52%，下界大于50% |
| 最新 Alpha、最新 Balance | 各自差值下界不低于−3个百分点 |
| 启发式、旧 Balance、Alpha v0.1.5 | 各自差值下界不低于−3个百分点 |

前两项与最新对手两项分别使用2.5%下分位。三个旧锚点使用0.05÷3下分位。另保留原合同的共同池−5个百分点、直接父代45%底线。

“下界”表示把抽样波动算进去之后的保守估计。点估计好看但区间太宽，就只能写“未确认”。这批局数不保证能识别2个百分点的小提升。

| 最终组合 | 应采取的研究判断 |
|---|---|
| 配比有效，且 B 超过父代并守住锚点 | 推荐 B 进入主线父候选评审；另轮检验多种子稳定性 |
| 配比有效，但 B 仍未超过父代 | 保留方法线索，M75 继续作父候选 |
| 配比未确认，但 B 候选门通过 | 候选可能有价值；不能宣称配比方法已有效 |
| 两项都未通过 | 保留 M75，按逐对手和回放证据决定下一假设 |

这些是结果解释规则。下一轮的具体方案必须依据实际结果编写，不提前排一串必跑实验。
