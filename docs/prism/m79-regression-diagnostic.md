# M79 退步诊断：先补训练覆盖，不给预留动作加惩罚

**建议下一轮从 M75 做原训练池与补覆盖训练池的配对小试。** 现有回放显示，策略变化主要涉及前中期拿宝石、购牌与预留路线；没有找到足以解释两类对手结果的单一残局错误。训练池遗漏启发式和旧 Balance，是当前最值得用对照实验验证的解释。

本次读取 **2,048 局现有回放**：M75、M79 各对启发式和 Balance v0.1.0 打过的 512 局，覆盖全部目标网格。重做了严格 Rust 回放核验，按同种子、同座位匹配；没有新对局或模型前向。

## 1. 先区分确定退步和可能波动

| 对手 | M75 半平得分 | M79 半平得分 | 变化 | 本次事后配对 95% 区间 |
|---|---:|---:|---:|---:|
| Heuristic v0.3.1 | 91.50% | 86.33% | −5.18 个百分点 | −8.79 ～ −1.56 |
| Balance v0.1.0 | 73.24% | 71.00% | −2.25 个百分点 | −7.32 ～ +2.73 |

启发式的退步有统计支持。旧 Balance 是本次点估计下降，尚不能确认真实退化；不应把两者都当成已经证实、必须修复的同一个缺陷。这里的区间是回放诊断中的事后分析，不覆盖原 M79 门槛。每个环境种子的双座位先合并，再做 20,000 次重采样，PCG64 seed=81009999。

逐局配对也保留了反向变化：启发式有 **58 局从赢变输、31 局从输变赢**；旧 Balance 分别为 **93、81 局**。不是原来会赢的局全部丢失，而是学习后的取舍改变了各类局面的结果。

## 2. 预留确实增加，但“多预留所以输”不成立

| 指标（每局均值，除标明比例外） | 启发式：M75 → M79 | 旧 Balance：M75 → M79 |
|---|---:|---:|
| 总预留牌数 | 2.93 → 3.38 | 3.63 → 4.01 |
| 买回预留牌数 | 1.29 → 1.70 | 1.68 → 1.97 |
| 直接买公开牌数 | 9.48 → 9.01 | 9.21 → 8.95 |
| 前 12 步预留公开牌数 | 1.04 → 1.33 | 1.21 → 1.48 |
| 能买到牌时，选择预留的比例 | 11.72% → 13.46% | 14.15% → 15.14% |
| 已买回预留牌的等待步数 | 5.43 → 5.07 | 5.86 → 5.47 |
| 有购牌直达 15 分机会，却没买牌的比例 | 5.78% → 3.07% | 4.63% → 4.11% |

条件分母是各自实际经历的可购买局面，并不等于两模型始终处于同一局面。可购买牌由玩家可见宝石、折扣、公开牌与本人预留牌计算；与 Rust 在 12,288 个第 4/8/12 步观测中的合法购买动作集合逐项一致，全轨迹实际购买也全部满足该判定。

直达 15 分机会的定义是“当前声望 + 可购买牌的印刷分 ≥ 15”；不包含购牌顺带获得贵族的额外分，也不等同于保证赢棋。启发式上未买牌的次数从 **27/467** 降到 **13/423**；旧 Balance 从 **17/367** 降到 **15/365**。这个检查不支持“终局得分机会变差”的统一解释。

更关键的是：**在胜率上涨的另外六个对手上，M79 每局预留也增加了 0.27–0.39 张。** 预留是整体策略变化的一部分，可能带来持有目标牌和金币的价值。直接处罚这个动作，可能同时破坏已经取得的收益。

## 3. 分歧往往从开局资源路线开始

我们比较相同种子、相同座位的两条回放，从开局逐步核对状态 SHA，定位第一个动作分歧。分歧前两边状态完全相同、对手动作一致；分歧发生在候选自己的决策。分歧以后，市场刷新和对手行动也会随之分流。

| 在“半平得分下降”的配对中 | 启发式 | 旧 Balance |
|---|---:|---:|
| 配对数（含赢→平、平→输） | 59 | 95 |
| 首次分歧在本人前 12 步 | 52 / 59 | 85 / 95 |
| 首次分歧是两边都拿宝石、但颜色/组合不同 | 41 / 59 | 57 / 95 |
| 首次分歧是父代买牌、M79 改预留 | 2 / 59 | 5 / 95 |

这些计数说明应检查前中期资源规划和对手适配，而不能只盯终局或预留动作。它们定位策略差异，**不能把最后输棋全部归因于第一步差异**：后续也是两套完整策略，不是只替换一个动作的受控回放。

两个可追溯例子（仅用于说明，不作因果估计）：

- **启发式，seed 17010022，候选座位 1。** 第 1 步前状态一致，M75 拿白/蓝/黑，M79 拿白/绿/黑。本人第 12 步分别 5 分与 3 分；最终 M75 以 16:7 获胜，M79 以 13:15 失利。M79 最后一步并没有可直接购牌达到 15 分的机会。
- **旧 Balance，seed 17012007，候选座位 1。** 第 1 步 M75 拿蓝/绿/红，M79 拿绿/红/黑；第 12 步分别 2 分与 0 分。最终 M75 18:15 胜，M79 17:17 但按游戏排名判负（同分不一定平局）。胜负始终读取回放 ranks，不用终局分数自行重判。

完整动作序列、首次分歧状态 SHA、原回放 SHA/远端路径及选例规则保存在本次诊断证据中。例子按“赢变输且首次分歧均为拿宝石，再按最早本人步数、seed、座位排序”确定。

上述两组共四份完整回放已按原 SHA 取回到 `local-artifacts/prism/m79-mainline/regression-diagnostic/cases/`，便于直接复查。

## 4. 最值得检验的原因：训练分布偏移

M79 的 5,120 局训练只覆盖 Prism v0.1.1、父代 M75、Alpha v0.2.0、Balance v0.2.1，各 25%；**启发式和 Balance v0.1.0 均为 0 局**。在这个训练分布上继续优化，可能提高与这些策略交手的资源规划，同时改变对未覆盖策略的应对。

这是有根据的工作假设，还没有受控训练证明。现有数据只有一条训练轨迹，不能排除随机训练波动；旧 Balance 的区间尤其宽。下一轮应直接测试覆盖变化，不同时调整奖励、学习率或网络，否则即使改善也难以判断原因。

选择：**M81 配对小试，A 保持四对手训练池，B 把 25% 训练份额分给启发式和旧 Balance。两臂同 M75 父权重、同训练种子、同 5,120 局、同 PPO，固定最终 c20。** 新独立评测用于检验恢复旧对手是否同时保住其他收益。M79 已被用于选假设，本次检查的数据不再充当 M81 的独立确认集。
