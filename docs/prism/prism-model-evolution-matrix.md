## 1. 评测规范与准入纪律 (Evaluation Protocol & Evolution Principles)

为确保新一代 Prism 独立神经模型家族（Entity-Relational Policy–Value Architecture）的演进具备严格的统计置信度、信息边界纯洁性与代码可追溯性，本项目确立以下评测准则：

1. **统一双换座对战基准 (128 种子双换座 = 256 局/配对)**：
   - 评测种子严格遵循 `scripts/s0_seed_registry.py` 的不相交段分配（Prism v0.1 基线种子段：`9_405_000..9_405_127`，已标记为 `consumed`）；
   - 对战双方严格执行对齐种子的双换座（Seat 0 先手 + Seat 1 后手），消除由发牌及盲牌顺序带来的单向偏差；
   - 统一采用 10,000 次配对 Bootstrap 重抽样计算 95% 置信区间 (95% CI)，量化统计不确定性；区间跨越 50% 时判定为均势/未决，不提前宣称统计断档超越。

2. **严格玩家视角与信息边界约束 (Strict Information Boundary, Zero Oracle Leak)**：
   - 模型特征输入严格限定为玩家可见信息（`Observation`、合法动作、显式实体及公开可重建的历史摘要）；
   - 严禁注入 `FullState`、真实随机种子、牌堆底牌顺序、对手暗牌、未来补牌或结果标签；
   - 市场与预留目标采用显式局部实体 Gather，而非固定槽位编号硬映射。

3. **保留有效负向证据，实事求是驱动演进 (Preserve Negative Evidence, Evidence-Bound)**：
   - 遵循 AGENTS.md 契约，任何未达标或均势的实验完整保留对战数据与战术归因；
   - 区分纯胜率 (Pure Win Rate) 与计半平得分率 (Score Rate)，单次评测通过仅代表确立实战基线，不自动等同于生产晋级。
