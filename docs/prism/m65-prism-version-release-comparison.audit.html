Agent 审计与历史研究指标

旧基建效用 = min(24, Σ min(3, 每张投资牌后续实际使用次数)) / 24。投资牌：本人前12个Main买入的0–1 VP牌；后续购买至Main24时，某色印刷成本达到该色折扣序号即记一次使用，不等同于反事实节省宝石。

时间加权效用 = min(24, Σ每张投资牌前3次使用的(25−使用Main序号)/24) / 24。前12Main平均折扣 = Σ前12Main末永久折扣 / 12；仅该描述量对早结束局保持终局值。这些是训练研究代理指标，不是小牌流派或晋级判定器。
