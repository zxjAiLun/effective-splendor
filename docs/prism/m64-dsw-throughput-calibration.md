# DSW 四核对战速度校准

**结论：后续采用4路并发，全部四核可用。** 它达到最快配置约97%的速度；5路反而较慢，6路只多约2.8%的吞吐。

本轮是工程速度校准：同一批256局双方greedy，在3/4/5/6路下各跑两次，共2048次执行。动作和胜负逐局一致，重复执行不计作更多棋力样本。时钟包括arena派发、保存回放、回放验核和报告，不包括准备、下载与逐局一致性比较。
