## 1. 评测规范与准入纪律 (Evaluation Protocol & Evolution Principles)

为确保启发式规则引擎（Heuristic Policy）的演进具备坚实的统计置信度与严格的代码可追溯性，本项目确立以下评测准则：

1. **统一双换座对战基准 (128 种子双换座 = 256 局/配对)**：
   - 评测种子严格遵循 `scripts/s0_seed_registry.py` 的不相交段分配（v0.2.9: `9_259_000..9_259_127`，v0.3.0: `9_270_000..9_270_127`，v0.3.1: `9_271_000..9_271_127`，v0.3.2: `9_271_999..9_272_127`，v0.3.2a: `9_272_999..9_273_127`，v0.3.2b: `9_273_999..9_274_127`，v0.3.2c: `9_274_999..9_275_127`）；
   - 每个基准对手严格执行对齐种子的双换座（Seat 0 先手 + Seat 1 后手），消除发牌顺序带来的单向偏差；
   - 统一采用 10,000 次 Bootstrap 重抽样计算 95% 置信区间 (95% CI)，客观量化统计不确定性；

2. **严格信息集约束 (Strict Information Set, No Oracle Cheating)**：
   - 启发式与搜索推演严禁偷看牌堆底牌（Deck Refill）；
   - 模拟推演中，市场卡牌购买或预留后**严格置空 (`None`)**，不补充伪卡或未知底牌，严格按根节点已知公开盘面与私有已知预留决策；

3. **保留有效负向证据，实事求是驱动演进 (Preserve Negative Evidence, Evidence-Bound)**：
   - 遵循 AGENTS.md 契约，任何未达标的实验（如初版搜索的参数偏差）必须完整保留对战数据与战术归因，绝不因结果不如预期而掩盖或修改评价门禁。
