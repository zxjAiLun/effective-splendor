两条不要混在一起的流水线

正在下这一盘

裁判状态→玩家观察 + 合法行动→策略 / 模型 / 搜索→行动→环境结算

正在改进下一版

采集对局→构造训练目标→预测与损失→更新参数→新 checkpoint→独立评估

Self-play 可以提供对局；PPO、搜索目标训练或 Q 学习规定不同的更新方式。实战选招中的 rollout 不自动触发训练。

观察与决策

State / FullState · 完整状态
裁判持有的完整棋局，包括隐藏信息。项目 live agent 不得直接获得它。目标 01
Observation · 玩家观察
某一玩家被允许知道的局面。可见历史也可能影响判断；不要把观察当成完整世界。
Action / legal actions · 行动 / 合法集合
买、拿、预留等具体选择及参数。规则负责合法性，策略负责偏好。
Policy · 策略
从观察/历史到行动或行动分布的决策规则。可以是人工规则，也可以是神经网络，并不天然意味着“训练过”。
Heuristic · 启发式
人工设计的经验判断。项目 heuristic policy 与供搜索使用的 StaticEvaluator 不要混称。
Inference · 模型推理
使用固定参数计算输出，不是更新参数。整个选招流程还可能调用搜索。目标 05
Search / successor · 搜索 / 后继局面
试走候选行动，再比较后果。到不了终局时可能需要价值估计。n1 也是根行动执行后的静态评分，不是只看原局面。目标 03
Determinization · 隐藏世界采样
基于已知信息构造可能完整世界用于模拟。采样世界不是现实真相；模拟玩家仍需遵守视角边界。
ISMCTS · 信息集蒙特卡洛树搜索
在隐藏信息问题中按可区分的信息组织搜索，而非把完整裁判状态直接变成玩家知识。目标 04
Prior / visits / PUCT-like · 先验 / 访问次数 / 选择规则
神经 policy 可提供搜索先验；搜索反复访问行动并累积价值判断。PUCT-like 规则结合价值与按先验分配的探索。项目有具体整数化规则，并非本表另定义一种算法。
Rollout · 模拟续走 / 采集轨迹
语义依上下文：S3 是候选后的策略模拟；RL 文献也常用这个词指采集一段环境交互。看到它先问“在模拟选招，还是在收集训练数据？”

训练与强化学习

Parameters / checkpoint · 参数 / 检查点
模型内可调整的数值，以及保存它们和必要身份/配置的产物。参数更新发生在训练，不是每次选招都发生。
Target / loss / gradient · 目标 / 损失 / 梯度
想让模型预测什么、当前差多少、局部往哪里改参数。目标错误或不适合决策时，损失降低也可能不改善棋力。目标 06
Self-play · 自博弈
由智能体相互交手生成经验的安排。它不是 PPO 的同义词；可以配不同训练目标。目标 07
Reward / return · 奖励 / 回报
环境给的数值信号 / 一段未来奖励的累计（可带折扣）。Splendor prestige 与 RL reward 不自动相等，须看任务合同。
V / Q · 局面价值 / 行动价值
某种继续策略下的期望回报；Q 还指定当前行动。都不天然是“绝对正确的答案”，数值解释依奖励与视角而定。
Advantage · 优势估计
某次行动相对基准预期的好坏估计。不是这张牌的分数，也不是“一赢就全盘行动为正”。
GAE · 广义优势估计
将不同时间跨度的 TD 误差加权混合来估计优势。gamma 和 lambda 角色不同。目标 09
Actor / critic · 行动策略 / 价值评估者
前者决定怎么选，后者提供价值/优势的估计依据。critic 预测更准未必足以让整个训练更强，M40A 就检验过这一点。
PPO · 近端策略优化
使用新旧行动概率比率与优势构建较保守的更新目标。Clipping 限制本样本的额外改进激励，不硬锁真实概率。目标 10：可调算例
On-policy / replay · 当前策略采集 / 经验回放
PPO 通常基于当前采集策略的一批新数据做有限更新；DQN 类方法可从回放缓冲中反复取历史转移。不同算法对数据来源与旧策略身份的要求不同。
Double-DQN / target network
在线网络选后续行动，目标网络给该行动估值，减少单一 max 估计的高估倾向。目标网络是计算目标的工具，不是人类正确答案。
C51 / prioritized replay
用 51 个支点表示回报的概率分布 / 按优先级抽取历史转移。分布型（distributional）不等于多机器分布式（distributed）。目标 11
Representation / pooling · 表示 / 池化
如何编码局面实体、再汇总它们。要保留颜色—需求等决策关系，而不只记总量。目标 12
Residual · 残差修正
保留基线，让模型学习补充修正；有可学的目标、模型学会了、实战受益是三件事。目标 14

研究证据

你看到的证据直接回答的问题不能自动推出
Smoke / 实现检查这条流程能执行吗？棋力提高
Held-out / 留出评估未训练例子上拟合如何？独立对战优势
Counterfactual / 反事实改变关键因素会怎样？所有真实局面都理解了
Ablation / 消融拿掉某因素影响多大？它是唯一原因
Arena / 对战冻结条件下对特定对手表现怎样？全世界最强
Confidence interval / 区间测量不确定性有多大？区间跨平手就是完全等强
Valid negative / 有效负向正确执行的方案没过哪道门？所有相似算法永远无效
